# PrevisaoCerta — modelo de arquivos (aluno)

Base para o seu projeto. **HTML e CSS estão prontos** (semântica + identidade visual). Nos arquivos de `js/` procure por `TODO`: cada um é uma função para você escrever.

1. Leia o **Documento Funcional** (o quê e por quê) e o **Refinamento Técnico** (como).
2. Abra esta pasta no VS Code e rode `index.html` com o **Live Server**.
3. Complete, nesta ordem: `js/storage.js` → `js/ui.js` → `js/api.js` → `js/app.js`.
4. Teste com o plano de testes (T1–T10) do Refinamento Técnico e rode o Lighthouse.

Enquanto os `TODO` não forem escritos, o console mostrará erros — é esperado.
